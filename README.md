A program that writes one funny single-line joke about a cat to `/output/entry.txt`, for the make.fun competition [The One-Line Cat Joke That Lands](https://make.fun/bounty/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262).

Run it with Python 3:

```sh
python3 main.py
```

It writes the joke below to `/output/entry.txt` (or to the path given as the first argument, or `$OUTPUT_PATH`) and prints exactly the joke. No network, no clock, no randomness. The joke is 104 characters, inside the 1 to 200 gate, a single line with no em dash.

## The joke

```
My cat knocked my phone off the table, then looked at me like I was the one who put it somewhere stupid.
```
